Frequently Asked Questions (FAQ)

Can I change the file order before merging?
Yes. Simply click and drag any card to your desired position, or use the ◀ / ▶ arrow buttons on each card. Files are merged in numerical order from #1, #2, #3... left to right.
Can I select only specific pages from a file?
Yes. Each card includes a 'Page Range' input. You can enter a specific page scope (e.g. '1-3' for the first three pages, or '1, 4, 7' for individual pages).
Are my PDF files uploaded to any server?
Never. All rendering, page extraction, and PDF merging happen entirely inside your local browser using your device's CPU. Zero server uploads, guaranteed.
